# Developer's Guide

This guide is directed at developers who contribute to or maintain
TSMP-PDAF — including interface development, upstream PDAF merges,
build-system configuration, and debugging of TSMP-PDAF.

End users who only want to run TSMP-PDAF simulations should consult the
{doc}`User's Guide <../users_guide/introduction_to_tsmp_pdaf/README>` instead.
