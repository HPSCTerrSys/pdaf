# TSMP-PDAF Documentation

The {doc}`User's Guide <users_guide/introduction_to_tsmp_pdaf/README>` is directed at
end users who want to build TSMP-PDAF and run simulations.

The {doc}`Developer's Guide <developers_guide/dev>` is directed at developers who
contribute to or maintain TSMP-PDAF — including interface development, upstream
PDAF merges, build-system configuration, and debugging of TSMP-PDAF.

The **Reference** section lists links to additional resources important
for TSMP-PDAF, as well as source code browsers for the TSMP-PDAF
interface and the PDAF library.
